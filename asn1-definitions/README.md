# ASN.1 definitions

The specifications the simulator's protocol code is generated from. Everything in
`src/asn/{rrc,ngap,xnap}` is compiler output from these files — nothing there is
hand-edited, and `tools/regen_asn1.sh` is the only supported way to change it.

| File | Protocol | Interface | Release |
| ---- | -------- | --------- | ------- |
| `rrc-rel18-v18_9.asn1` | RRC — Radio Resource Control (TS 38.331) | Uu, gNB–UE | Rel-18, v18.9.0 |
| `ngap-rel18-v18_9.asn1` | NGAP — Next Generation Application Protocol (TS 38.413) | N2, gNB–AMF | Rel-18, v18.9.0 |
| `xnap-rel18-v18_8.asn1` | XnAP — Xn Application Protocol (TS 38.423) | Xn, gNB–gNB | Rel-18, v18.8.0 |

RRC is encoded with UPER, NGAP and XnAP with APER.

## Regenerating

```
tools/regen_asn1.sh              # all three
tools/regen_asn1.sh rrc          # one protocol
```

Regeneration is reproducible: running the script without changing a specification or the
compiler leaves the tree byte-identical, so `git status` after a run is the check that the
checked-in code really is the output of these inputs. The exact command is also recorded in
the preamble of every generated file, with repository-relative paths, so it can be re-run by
hand from the repository root.

## Toolchain

Generated by a **fork** of asn1c, not the stock compiler:

- repository: `/home/joe/repos/asn1c-r18`, branch `prefix-identifiers-and-aper`
- commit: `bd8605150035729618dbc9ecd3fb90aaed63bd2a`
- override the location with `ASN1C_REPO=/path/to/asn1c-r18 tools/regen_asn1.sh`

Three things in that fork this project depends on, none of which stock asn1c 0.9.29 does:

1. **`-fprefix` prefixes C identifiers**, not just filenames and include guards. All three
   trees link into one binary, so without this they collide on thousands of `asn_DEF_*`
   symbols.
2. **The skeletons implement APER** (aligned PER, X.691). NGAP and XnAP need it.
3. **Value assignments are emitted as constants**, so `id-NAS-PDU ProtocolIE-ID ::= 38`
   becomes a usable `#define` instead of a number to copy by hand.

`src/asn/asn1c` is the shared runtime and is byte-identical to that fork's `skeletons/`.
Regeneration rewrites it as a side effect of `-fcommon=asn1c`; that is a no-op, and
`tools/check_asn1_runtime.sh` verifies no protocol tree has grown a private copy.

## Local deviations from the published specifications

These files are otherwise the 3GPP releases named above. One line is not:

- **`rrc-rel18-v18_9.asn1`, `PhysCellId`** — the `(0..1007)` constraint is removed so the
  36-bit NCI this project transports in `physCellId` can be encoded. Marked with a comment
  at the definition; rationale and consequences in `docs/ASN1_R18_Migration_Plan.md` §9.2.
  This makes `physCellId` wire-incompatible with real 3GPP equipment.

Unrelated to the above: `tests/data/asn1_specs/` holds a **Rel-15.6** copy of TS 38.331 that
the Python test harnesses compile with `asn1tools`. That is a test fixture, not a compiler
input, and it is deliberately a different release from the one here — see
`docs/ASN1_R18_Migration_Plan.md` §9.5.
